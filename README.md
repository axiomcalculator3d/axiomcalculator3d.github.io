# axiomcalculator3d.github.io

O site do Calc 3D fica em https://axiomcalculator3d.github.io/calc3d/ (repositório `calc3d`).

Este repositório só segura o que precisa ficar na raiz do endereço:

- `index.html`: leva quem abrir a raiz para o site do Calc 3D.
- `app-ads.txt`: o AdMob procura este arquivo na raiz. Não apagar nem mover.
- `exclusao-de-conta.html` e `account-deletion.html`: levam às páginas de exclusão de conta,
  que agora ficam em `/calc3d/`. Ficam aqui para o endereço antigo cadastrado na Play continuar abrindo.
